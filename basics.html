Game Basics and Hotbar Guide

Starting Out

When you first login, you'll spawn in a starter zone with a beginner's guide. Navigation uses directional buttons in the top right, while the top middle displays timers for daily bonuses, server time, and quest availability.

Information can be accessed through in-game commands, Discord, the wiki, or by asking other players in chat.

Combat works by selecting "Fight" in monster areas, then choosing to "Attack" (using equipped weapons) or "Cast" (using spells). As you defeat enemies, you gain levels to strengthen your character and equipment.

Most windows feature a "Pin" button to prevent the screen from defaulting back to the Stats page after actions.

Informational Window (Top Left)

The informational window displays:

  • Rank & Name: Your ranking among players
  • Exp Bar: Progress toward your next level
  • Character Info: Alignment standing, level, race, and profession
  • Core Stats:
  • Strength: weapon damage and gear requirements
  • Dexterity: weapon accuracy; primary for fighter classes
  • Intelligence: spell damage and gear requirements
  • Wisdom: spell accuracy; primary for caster classes
  • Vitality: maximum health; primary for vampires
  • Health: Current HP (death occurs at 0)
  • Gold: Carried currency (lost upon death)
  • Bank: Vault currency (safe from death)
  • Experience: Current XP; resets after leveling
  • Next Level: XP required for level-up
  • Class Type: "Fighters," "Casters," or "Elites" (13 total builds); maintaining stat hierarchy preserves class perks
  • Alignment: Cosmetic morality gauge based on PvP kills and special monster defeats

Hotbar (Quickbar)

The green bar contains these sections:

Window Function
Stats Window Character power display
Inventory Window Equipment/items with sort options (A-Z, Gems, Gear); includes Strip button
Loadout Preset gear switching (requires Estate upgrade)
Trade Player-to-player commerce; one active trade at a time
Estate Secondary inventory with additional features
Clan Armory Third inventory option
Training Log Window Session data (levels, kills, drops, masteries) with toggle settings
Battle Info Window Active buffs, daily/personal bonuses, zone modifiers, and stacked bonuses
Command Window "/" commands for information and utilities like "/myth" (gear upgrading) and "/id [player]" (stat checking)
Quest Window Tracks special monster progression
Settings Window Display options, dark mode, timer visibility, chat color preferences, button positioning
Map Window Zone layout with portal (E) and interaction markers (unavailable in some zones like The Wilderness)
Manual Window Links to the Wiki
Logout Exit game
