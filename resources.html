Resources

Overview

The game features a separate resource drop system independent from traditional loot pools. The default drop rate is 1/100, though this varies by zone. Resources can drop simultaneously with normal items.

Nine Available Resources

Lumber Estate building; some Conquests

Additional Acquisition Methods

Resources can be obtained through:

  • Fleet Admiral conquest rewards (increases with progression)
  • Quest completion (approximately 500-1000 per quest)
  • Disassembling Shadow Gear yields Fusion Pieces
  • Resource Plot Locations in Scorched Dunes, upgradeable via Estate Excavation Site

Finding Resource Information

Use the "/zoneres" command to identify which zones drop specific resources. Zone data updates frequently, making this tool essential for resource hunting strategies.
