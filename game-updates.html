Game Updates

Feature Update Access Methods

Players can learn about new features through several channels:

  • Discord Server
  • In-game via the /oas command
  • In-game /updates command displaying changes since Summer '19
  • Login page (top right), with older announcements available via "older news" link

Balance Adjustments

Buffs: When game elements underperform, adjustments occur immediately for gear, gems, zones, and similar features. These changes are communicated "in-game and discord, but usually not the other methods."

Nerfs: Modifications reducing power occur at round beginnings or when unreleased content is involved. The policy ensures consistency—if players haven't accessed a level 500 zone yet, its nerf applies immediately. However, if players already occupy that zone, adjustments wait "until the beginning of the next round."
